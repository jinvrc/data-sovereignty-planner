# Data Sovereignty Planner

Набор AI-скиллов для управления личными данными без вендор-зависимости.

Основан на реальном опыте автора, столкнувшегося с изменением условий хранения в Яндекс.Диске. Помогает:

- оценить риски по каждому провайдеру,
- спланировать распределённое хранение (облако + локаль),
- провести миграцию или чистку,
- закрепить персональную политику, чтобы не попасть в ту же ловушку.

## Навыки

1. **Data Inventory & Risk Auditor** — инвентаризация и тепловая карта рисков.
2. **Backup & Distribution Strategist** — стратегия распределения данных по независимым хранилищам.
3. **Vendor Lock‑in Breaker** — пошаговый план миграции из проблемного сервиса.
4. **Data Cleanup & Retention Planner** — ревизия, удаление дублей и архивных файлов.
5. **Personal Sovereignty Policy** — персональный контракт с самим собой по управлению данными.
