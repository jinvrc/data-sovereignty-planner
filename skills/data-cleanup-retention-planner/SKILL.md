# Data Cleanup & Retention Planner

## Описание
Помогает провести ревизию и удалить дубликаты, устаревшие версии, временные файлы, чтобы уложиться в бесплатные или дешёвые тарифы. Группирует файлы по категориям: «нужно сейчас», «можно удалить», «заархивировать». Даёт инструкции по автоматической чистке (скрипты, утилиты).

## Входные данные
- Инвентаризация (из первого скилла) или список папок с размерами
- Новые лимиты провайдера (например, 10 ГБ вместо 16)
- Критерии важности: давность доступа, размер, тип файла, кто создал

## Выходные данные
- Список файлов к удалению (с причинами)
- Список файлов для архивации (с предложением, куда архивировать)
- План регулярной (ежеквартальной) чистки с календарём
- Рекомендации по инструментам для дедупликации (Duplicate Cleaner, fdupes и пр.)
- Шаблон отчёта о чистке для себя

## Рабочий процесс
1. Просканируйте хранилище и соберите метаданные (дата изменения, размер, тип).
2. Примените правила очистки:
   - удалить временные файлы (кэш, .tmp)
   - удалить дубликаты (по хешу)
   - переместить в архив файлы старше X лет, если к ним не было доступа за Y месяцев
3. Сформируйте список на удаление и покажите пользователю для подтверждения.
4. После подтверждения — выполните удаление (можно сгенерировать команды).
5. Обновите инвентаризацию и запишите дату чистки.

## Пример использования
> «Яндекс ограничил 10 ГБ. Помоги найти и удалить всё, что старше 5 лет и не открывалось за год. Предложи регулярный скрипт для автоматической очистки папки "Загрузки".»

## Принципы дизайна
- Безопасность: перед удалением всегда запрашивать подтверждение.
- Возможность восстановления из корзины/архива в течение 30 дней.
- Автоматизация с помощью скриптов (bash, PowerShell) — с пояснениями.
- Все действия логируются.
